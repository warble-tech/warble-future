How it works

Scan. Observe. Propose. Apply only inside policy.

Community Edition is a complete self-host path. Enterprise adds tenancy, billing, and a managed control plane — not a different agent loop.

1

Scan — ShrikeOps

Misconfigs, CVEs, and deprecated APIs before they ship. Open source, runs in CI or on the cluster.

2

Observe — Heron Ops

Live pods, logs, events, and metrics over MCP. Any agent IDE. No write required for the first path.

3

Coordinate — Starling EX CE

One Helm chart. Propose next steps; optional guarded apply. No license phone-home.

4

Enterprise — private beta

Warble Cloud multi-tenant plane, GitHub App, or managed FRAKMA. Same flock underneath. Closed while we take a small set of design partners.
